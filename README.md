# PURCHASING-SYSTEM

A professional purchasing and expense tracking system featuring a dynamic list table, a product search bar, data segmentation, and a percentage-of-total chart. 

The pricing scales in this system were entirely inspired by supermarket chains operating in Perth, Western Australia.

---

## 🚀 Features
- **Dynamic List Table:** Organizes inventory and product data cleanly.
- **Product Search Bar:** Allows fast filtering and lookups for specific items.
- **Data Segmentation:** Segregates data efficiently to analyze metrics by category.
- **Percentage-of-Total Chart:** Visualizes spending and inventory distribution (ECG-style layout).

## 🛠️ Built With
- **Microsoft Excel / Google Sheets:** Advanced formulas, data formatting, and charting tools.

## 📂 How to Use
1. Download the `.xlsx` file from this repository.
2. Open it in Microsoft Excel or Google Sheets.
3. Use the search bar and filters to interact with the dashboard and explore the pricing scales.
